# ADR-0006: Built-in Fluent ORM

Status: Accepted

## Context

GoKS wants zero-config local development and type-safe data access without
forcing developers to adopt a separate, heavyweight ORM dependency.

## Decision

Ship a built-in, fluent, type-safe query builder (`pkg/orm`,
`orm.Query[T]().Where(...)`) with auto-timestamps, soft deletes, migrations,
and zero-config local SQLite (`orm.OpenSQLite("app.db")`).

## Consequences

Positive:
- Type-safe queries using Go generics.
- Zero-config local development experience.

Negative:
- GoKS now owns ORM correctness/security (SQL injection safety, migration
  safety) rather than delegating to a mature third-party library.
- Additional database adapters beyond SQLite are additional maintenance
  burden — only add with a concrete need (see `.agents/roadmap/03-backend.md`).
